# VelocityBroadcast
This is a broadcast plugin for Minecraft Velocity proxies.

#### **Commands:**

- `/bactionbar id text`
- `/btitle id text`
- `/delbar id`
- `/bbossbar id text`



### Permissions:
> - ```velobroadcast.bossbar```
> - ```velobroadcast.actionbar```
> - ```velobroadcast.send```
> - ```velobroadcast.reload```
> - ```velobroadcast.title```
